# Contributing

Describe the Revit, pyRevit and IronPython versions, the exact command and expected/actual behaviour. Reproduce with a fictional model or sanitised exchange JSON; never submit private model data. Maintain the original version 1 project schema and model/element identity checks. New Revit-specific features require host testing and a clear statement of limitations. Run the offline tests before submitting a pull request. Preserve text-only writes and transaction preview unless deliberately designing a new feature.
